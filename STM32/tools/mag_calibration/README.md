# IST8310 磁力计标定

当前系数是 **2026-11-05 这块单独开发板、当前环境下的改善候选**，不是通用 C 板参数。系数已接入现有 `INS_task.c` 的 `imu_cali_slove`；不增加任务、外设、Flash 参数管理或保护框架。

## 来源与公式

用户提供的战队参考包 `basic_framework`、`librm` 未找到可直接使用的完整磁力计标定实现。本工具的拟合模型参考 [PX4 `lm_mag_fit` / `lm_ellipsoid_fit_iteration`](https://github.com/PX4/PX4-Autopilot/blob/30e763b6780061d70a14894e3e8b06e6a656f9b8/src/modules/commander/lm_fit.cpp)，固定版本 `30e763b6780061d70a14894e3e8b06e6a656f9b8`；[BSD-3-Clause 许可](../../LICENSES/PX4-BSD-3-Clause.txt)已保留。这里不能称为战队磁标定源码移植。

先拟合球得到半径 `R`，再固定 `R`，最小化 `R - ||A(m - b)||`。`b` 是三轴硬铁偏移，`A` 是六个独立参数的对称软铁矩阵。求解器使用 SciPy，输入归一化、求解与统计为本工程电脑端适配，没有复制 PX4 的迭代求解器。

输入 `m` 和偏移 `b` 都在 **IST8310 芯片坐标系，单位 µT**。板端只执行一次 `mag_corrected = A × (mag_raw - b)`，再进入现有九轴 Mahony；当前 IST8310 安装矩阵为单位阵，已与 `A` 合并到 `mag_scale_factor`。原始 `ist8310_real_data.mag` 保持不变。球拟合半径不是独立测得的地磁强度，模长标定不能识别任意磁力计/IMU安装旋转或地理北。

## 本轮数据与限制

原始芯片坐标数据及参数保存在 [data/2026-11-05](data/2026-11-05)：`fit.csv` 用于拟合，`validation.csv` 来自第二轮独立翻转，只验证首轮参数，不参与拟合；`calibration.json` 保存完整参数、模长统计和方向覆盖。

首轮计划采集180秒，末尾发生复位，复位前取得16424个完整帧，CSV保留8850个相邻不同值。第二轮采集120秒，取得12000帧，CSV保留6466个相邻不同值。临时采样仅把原 `vofa_send` 的三个参数改为最新原始磁场XYZ，沿用100Hz发送，因此可能复用上一次磁力计读数；CSV仅删除连续完全相同的三轴值，没有按幅度剔除异常值。这不是实时DRDY日志，不能将8850点称为8850个独立噪声样本。

| 原始标准差 / 相对标准差 | 10.531 µT / 22.82% | 9.247 µT / 19.67% |
| 校正后标准差 / 相对标准差 | 3.428 µT / 8.14% | 2.782 µT / 7.14% |

两轮均覆盖八个象限，首轮系数在第二轮仍降低模长波动，但残差和两轮均值差仍明显。单独拟合第二轮作一致性检查，两轮矩阵去掉整体尺度后的相对差约1.22%，偏移差模长约2.39 µT；两套参数作用同一数据的磁向量方向平均相差约2.5°。因此当前参数具有改善证据，不能承诺绝对航向精度或 yaw 漂移改善。安装到车上后需要复验；静态模型不能补偿随电机电流变化的磁场。

## 复现

在仓库根目录执行；脚本只处理CSV，不读取串口、不烧录参数。CSV须为三列原始磁场µT，可带一行表头。

```powershell
python -m pip install numpy scipy
New-Item -ItemType Directory -Force tmp | Out-Null
python tools/mag_calibration/fit_magnetometer.py tools/mag_calibration/data/2026-11-05/fit.csv -o tmp/mag_calibration_check.json --validate tools/mag_calibration/data/2026-11-05/validation.csv
python tests/test_mag_calibration.py
```

测试覆盖非对角旋转椭球、偏移、噪声及独立方向验证，并检查平面/静止退化、求解失败时不写参数。秩、正定性和收敛检查只在电脑端执行。方向覆盖和残差由测量者评估，不以随意设置的精度阈值自动宣布标定成功。本机沙盒若系统临时目录不可写，可先将 `TEMP`、`TMP` 指向仓库内已创建的 `tmp`，再运行测试。

## 再次采集时怎样转动

先保持板子静止，等待已有的45℃预热、稳定2秒和约10秒陀螺仪零偏标定结束。**开机静止标定与磁力计转动采样是两个阶段**；确认临时磁场输出已开始、采集程序就绪后再转动。

选择远离铁桌、磁吸物、电机及大电流线的位置，尽量在同一小范围内缓慢翻转板子：绕三个轴各转几圈，让正面、背面和四个侧边都朝过上方；不要只做水平转圈。约2～3分钟覆盖各种方向，随后单独再采一轮相同方式的翻转用于验证，参数仍只由第一轮拟合。固定在板子上的部件、供电和走线尽量保持与使用状态一致；装车后单板候选参数需重新核验。

采集结束后必须恢复正常输出。**当前正式固件仍是 JustFloat 三个姿态角 roll、pitch、yaw（度）**，不是磁场通道；不要把正常角度帧保存为磁场CSV进行拟合。
