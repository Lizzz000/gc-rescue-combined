| 目录 | 用途 |
| --- | --- |
| `firmware/` | USB 类型 2 手动、USART6 遥控和 SWD 测试固件。按原构建模式选入，通过公共接口调用底盘、里程计和通信分帧。 |

在 [STM32 工程目录](../project) 构建固件。USB 手动使用 `Debug`，串口遥控使用 `Debug-UART6-Manual`，SWD 联调使用 `-DCHASSIS_TUNING_ENABLED=ON`。相关回归仍由 [STM32 主机测试](../tests/run_native.py) 和 `STM32/tests` 下的工具测试运行。

## USART6 底盘遥控

在 `STM32/project` 下运行 `cmake --preset Debug-UART6-Manual` 和 `cmake --build --preset Debug-UART6-Manual`，产物在 `build/Debug-UART6-Manual`。这个预设用 USART6 独占控制和状态回传。普通 USB 手动、自动搬运和 SWD 联调继续使用各自的构建模式。

J29 使用 3.3 V USB–TTL，共地。模块 TX 接 PG9/RX，模块 RX 接 PG14/TX。串口是 115200、8N1。电脑安装 Python 的 `pyserial` 后，从仓库根目录运行 `python STM32/manual_test/uart6/uart6_manual.py --port COM7`，将 COM7 换成实际端口。工具使用 Python Tk 窗口。

| 操作 | 条件与行为 |
| --- | --- |
| Enter | 接管已上电使能的底盘，或在显式失能后重新申请使能；零速就绪时可归还控制。 |
| W/S、A/D、Q/E | 前后、左右、逆/顺时针，松键发零速并保持使能。默认平移 0.40 m/s、转向 3.0 rad/s。 |
| O | 底盘停稳且里程计有效时保存当前位姿为原点，界面显示原点坐标系中的相对 X、Y 和航向。再次按 O 可重建原点。 |
| R | 零速就绪且原点有效时沿直线返航，同时恢复原朝向。默认限速 0.40 m/s、3.0 rad/s，起步距离最多 1.5 m，超时 20 s，到位复核窗口为 2 cm/10°。 |
| 空格、窗口失焦 | 空格始终请求停车并失能。运动时失焦也会急停，空闲时失焦会向支持正常归还的固件交还控制。 |

电脑以 20 Hz 发速度帧或返航保活。250 ms 无有效控制帧进入制动，停稳或制动达到 500 ms 后失能。返航期间里程计失效、触及范围边界或动作超时也会停车。失能后原点清空，重新使能、停稳并按 O 后才能再次返航。返航直线须保持空旷；到位窗口以里程计估计核验。

串口复用 A5/版本 01/类型/长度/载荷/CRC-16 的分帧。类型 2 沿用手动速度格式；USART6 专用帧如下。整数按小端传输。

| 类型 | 载荷 |
| --- | --- |
| 0x40 / 0x42 | 使能、建原点，各带非零 `uint16` 请求号。 |
| 0x43 | 返航。长度 2 使用 0.40 m/s、3.0 rad/s。长度 6 再带两个正 `uint16` 限速，单位 0.001 m/s 和 0.001 rad/s，分别至多 400、3000。 |
| 0x41 / 0x44 | 停车、返航保活，空载荷。 |
| 0x46 | 正常归还，长度 2，载荷为非零请求号。收到匹配 DONE 后会话及原点清除，底盘零速带电待命。 |
| 0x80 | 状态、标志、请求号（uint16）、命令、结果、原因。bit0 原点已建，bit1 里程计有效，bit2 零速待接管，bit3 支持新限速与正常归还。 |
| 0x81 | 相对 X、Y、航向，三个 `int16`，单位依次为 mm、mm、0.01°。 |

板端首先架空验证方向、松键停车、失焦和拔线制动；再在空旷地面低速平移并转向，核对原点显示和返航实走终点。

2026-11-18 使用 DAP-Link（HID/SWD，480 kHz）烧录并校验串口遥控固件。架空时通过 COM9 验证前后、左右、双向转轮、松键停车和串口断流失能。里程计返航从相对坐标 (17, 20) mm 到 (4, 3) mm；这是车轮架空条件下的编码器闭环结果，实车地面位移和车身回转尚待验证。

### 网页遥控

使用同一份 `Debug-UART6-Manual` 固件。此预设由 USART6 独占底盘指令；Jetson 自动搬运使用单独的 USB 固件模式。关闭占用串口的桌面遥控或 VOFA，在仓库根目录运行：

```powershell
python STM32/manual_test/uart6/uart6_web.py
```

网页默认打开 `http://127.0.0.1:8765`。选择实际串口（本次场测为 COM7），连接后先观察板端状态。接管就绪后可以定时运行或按键遥控。

定时运行先选方向，再设平移或转向速度和秒数。到时发送零速并保持使能。按键遥控用 W/S、A/D、Q/E，或按住页面上的按钮。松键后也发零速。两种模式都可立即下达下一条运动指令。斜向同时按时，合速度缩回设定的平移速度。返航平移和转向在页面上单独填写，经长度 6 的 `0x43` 发给板端。运行和返航都受底盘现有加减速限制。

空格或「停车并失能」可中止动作。本页正在驱动底盘时失焦或关闭会请求急停。正常松键或定时结束后，空闲控制页可归还会话并保留使能。只查看状态的标签页可随时切走。按住超过 0.25 秒没有新的按键心跳时，网页改发零速。活动会话的串口断流和页面失联保护持续生效。

网页和桌面工具共用 `pyserial`。若当前 Python 缺少该包，运行 `python -m pip install pyserial`；本地已经随架空测试保存了依赖副本，可以先设置 `$env:PYTHONPATH = (Resolve-Path 'STM32/project/build/Debug-UART6-Manual/serial-test-deps').Path` 再启动。
