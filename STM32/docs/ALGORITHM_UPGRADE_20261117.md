# STM32 算法升级与回归（2026-11-17）

本轮仅修改 STM32。模块入口见 [算法目录](../project/Core/Algorithm/README.md)；源码保留现有三轮接口、轮序、使能/故障语义与静态内存方式。真实 Jetson 视觉暂不可用，板端使用注入图像坐标测试。

## 实现与取舍

| 模块 | 本轮处理 |
| --- | --- |
| AHRS | 保留 Mahony 增益与融合主体；补充有限输入、四元数范数、dt 及缺失传感器处理，欧拉角计算复用平方项 |
| PID | 保留正常离散/连续控制规律，统一限幅与抗积分饱和；非法输入和运算溢出清状态并输出零 |
| Kalman | 源帧时间驱动、展开 Joseph 协方差、NIS 异常抑制与三帧重捕获；保留原正常观测增益规律 |
| 视觉速度 | 新增 `visual_servo.*`，制动距离限速、两轴合速度/加速约束、换向过零和入窗轴停车，取消视觉积分与最小爬行速度 |
| 运动学/里程计 | 固定后/右前/左前轮约定，几何常量倒数预计算，具名输入模式；编码器位置差＋SE(2)，航向升级为YAW主导平面ESKF；旋转等效臂长相对标定98.2mm |
| 点到点规划 | 新增 `point_plan.*`，无障碍平面直线最短路径与最短角差，平移/旋转同时控制，近段制动限速 |
| 测试工具 | 命令8注入原始图像坐标，命令7里程计返航；USART6提供坐标生成所需遥测，DAP-Link发送命令/坐标/心跳 |

参考通过用户指定的 GitHub 与 SciSpace 查询核对。具体固定版本、论文链接和许可在 [Kalman](../project/Core/Algorithm/Vision/README.md)、[Chassis](../project/Core/Algorithm/Chassis/README.md)、[AHRS](../project/Core/Algorithm/AHRS/README.md)、[PID](../project/Core/Algorithm/PID/README.md) 中记录。未移植 ROS、Eigen、MPC/LMI 求解器；未将论文稳定性结论套用到本实现。没有地图输入，直线最短仅适用于已确认的空旷区域。

视觉响应初值为10000q/m，执行延迟余量0.12s另加实际帧间隔；加速0.40m/s²、减速0.35m/s²，底盘原斜坡0.45m/s²。真实相机投影、深度及延迟仍需标定，不能保证所有工况绝对零过冲。

## 主机正确性与模型验证

- 最终33套 native 测试与9种控制模式预处理通过，包含真实C算法和控制状态机。
- Python全量97项回归通过；包括串口碎片/重同步、USB桥旧缓存拒绝、坐标变换、会话异常停止和模拟返航。
- Kalman覆盖15/30/50/100fps与丢帧等32个场景。与修改前自适应版本同轨迹/种子比较，静止、加速、噪声突增的位置RMS比均约1.000，孤立误检约0.636。
- 视觉控制的24组闭环模型覆盖多帧率、5000/10000/20000q/m响应、异常帧、60ms视觉延迟及执行器滞后；8向点到点闭环模型约6.4s完成1.2m，估计终点约7.5mm。这些是模型结果。
- 五种ARM构建通过：`Odometry-Live-Test`、`code-opt-debug`、`code-opt-release`、`odometry-auto`、`odometry-chassis-test`。视觉阶段专用构建RAM35976B、Flash108440B；最终ESKF旋转测试版RAM36168B、Flash113928B。

日志：`STM32/outputs/algorithm_native_final.log`、`algorithm_python_final.log`、`algorithm_build_*.log`。SciPy与pyserial仅安装到忽略的`outputs/validation_deps`验证目录，未改全局Python环境。

## 性能对照边界

`benchmark_algorithms.py`以提交`59f53131662ab3d40e81623adb500deb4ee7d841`为基线，实际C源码、PC GCC `-O2`、无fast-math，交替7轮、每项100万次，取中位数：

| 算法 | 修改前 ns/次 | 修改后 ns/次 |
| --- | ---: | ---: |
| AHRS更新 | 16 | 16 |
| 欧拉角 | 137 | 137 |
| PID | 7 | 10 |
| 运动学 | 11 | 10 |
| Kalman | 64 | 21 |
| 编码器里程计 | 115 | 113 |

PID增加输入防护有约3ns的PC开销，不能宣称每个函数均更快。PC时钟粒度和运行环境影响这些数值，尤其不能将Kalman的PC加速比例等同于Cortex-M4加速比例。前表未包含后续新增ESKF，不能用原始YAW入口基准冒充ESKF性能。最终板端TIM2测得里程计＋ESKF最后38µs、最大观测42µs；尚未测量各算法DWT周期或证明WCET。板端运动/反馈回归用于检查运行行为与数据新鲜度。

## 最终固件板端回归

首轮专用ELF SHA256：`efd373a25ad461479f8a8a6d64de1fac271fa3c4ae11ef3ae773642d33809a07`；BIN SHA256：`3afcd29ff91b844e5b120bbdf7e4424f6da5974abc704feea40d42c90543bbba`。DAP-Link烧录后完整Flash加载段逐字节一致；USART6 PG14/PG9、115200 8N1，电脑端COM7。原始记录在`STM32/outputs/algorithm_upgrade_20261117/`。

用户确认前方2m、左侧至少1m净空，测试目标为先转60°、前方1.2m/左侧0.6m的注入视觉接近，随后按直线最短路径返回本轮原点；限速0.20m/s、0.50rad/s。此处60°是请求角度，以实际IMU估计另行评估。

第一次`mission.jsonl`在去程触发错误5，未完成返航。源帧间隔最大297ms，超过250ms有效期，期间心跳仍更新；最终STOP确认三轮失能、目标全零。只读测量显示71字SWD读取约60ms，长于视觉快照40ms发布周期，导致整包seqlock反复重读。提高SWD时钟未消除瓶颈，最终保持480kHz。

据此测试工具改为USART6整帧遥测＋短SWD命令/当前时钟读取；坐标提交仍按数据先写、序号最后提交。串口打开时还观察到USB桥遗留的旧帧，因此加入与板端当前发布时间的比较，旧帧不能用于生成坐标。第一次静止传输检查`recover.jsonl`因旧缓存时间跳变中止，没有发送运动命令；该失败与原始日志保留。没有放宽250ms坐标或300ms心跳有效期。

`recover2.jsonl`静止验证35帧、最大源间隔40ms，随后6.750s返回保留的原点。第二次`mission_uart.jsonl`视觉去程8.440s成功，估计终点误差9.631mm，206次坐标注入最大间隔47ms；返航中一次DAP TCP读取超时导致保护停止，整轮仍判未完成。工具关闭TCP小包等待，并在等待串口后、读取SWD前续接已有心跳；只读会话不启动心跳。未放宽超时保护。

第三次`mission_final.jsonl`静止时序检查和回原点通过，202次视觉注入最大间隔63ms。去程原始坐标进入100q窗口时，世界误差20.270mm，触发了误用返航20mm门槛的错误9。6000q/m投影下，100q矩形窗口加15/25q噪声本来就约对应28.3mm径向范围，不能同时宣称20mm圆形到位。只将命令8的世界交叉核验设为35mm（含制动余量），命令7仍20mm；新增20.27mm接受、36mm拒绝及命令7不放宽的边界回归。没有借助里程计生成视觉段的运动速度。

更新前再次返回保存的本轮原点（7.640s），确认停止再烧录。最终ELF SHA256为`59b0c4ac7c6ad32bf7e5ac6009525b05a8f4a306faea5389f55750de6bb6aeac`，BIN SHA256为`737f4b71b8499e75d003182cce7e29d521c6a1ce36562d4baadec73f9da57822`；完整Flash核对一致。新记录在`algorithm_upgrade_20261117/final/`，重新以更新后当前位置建立本轮原点，不把复位前坐标直接混用到新坐标系。

最终修正版的`final/mission.jsonl`视觉去程8.155s完成，返航开始后再次出现DAP读取超时，最终STOP确认。该轮没有完成完整返航，不计为整轮通过；TCP小包设置和读取前续心跳没有解决全部DAP读取长尾。用户确认现场无拉线、松动或重连提示，随后改为同向30圈YAW测试。前述去程通过和单独恢复返航通过不能合并冒充一次完整任务成功。

30圈任务将运动期间的SWD诊断读取移除，只发送心跳、用USART6取回数据；结果单列于 [旋转YAW记录](SPIN_YAW_20261117.md)。历史里程计长路线见 [ODOMETRY.md](ODOMETRY.md)。


最终ESKF按YAW计圈的2/3/4/3/2rad/s同向30圈用时74.22s，保持使能零速。YAW30.001圈、轮角30.024圈，ESKF/YAW动态RMS0.028°；用户现场反馈平顺、可能少转约30°，实际角度精度仍未验收。此结论与内部传感器一致性分开记录于[旋转/ESKF记录](SPIN_YAW_20261117.md)。最终回归日志为`STM32/outputs/eskf_native.log`、`eskf_python.log`、`eskf_build*.log`。
