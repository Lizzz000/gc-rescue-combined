# 同向30圈旋转与YAW主导ESKF（2026-11-17）

正式里程计已接入平面ESKF：gyro预测、AHRS YAW主观测、编码器转角弱约束。用户反馈新一轮动作平顺，但现场目测约少转30°。因此，本轮控制流程、连续遥测和停车通过，**不能认定实际转角精度通过**。保持电机使能、目标全零，未自动补转。

## 旋转几何修正

原轮计实验五个稳定速度段的YAW/轮角比例为1.09847、1.10181、1.10155、1.10048、1.09924，存在一致的约10%比例差。用户指定“信任YAW、降低编码器”，并提示安装尺寸可能有误差，因此只相对校准旋转项：

`108mm × 29.998987 / 33.007299 = 98.1568mm`，取`CHASSIS_ROTATION_RADIUS=0.0982f`。

`CHASSIS_CENTER_DISTANCE=0.108f`保留为名义机械尺寸；轮半径35mm、平移投影、后/右前/左前轮序及电机安装方向不变。98.2mm是相对于选定YAW的等效臂长，混合了几何、轮接触、轮径和传感器比例等效应，不能证明实际中心距为98.2mm，也不能识别三轮各自安装误差。

## ESKF接入和性能

`Core/Algorithm/Chassis/heading_eskf.c`使用名义航向/陀螺偏置、两维误差、2×2单精度协方差；Joseph更新、SO(2)误差注入与复位，无动态内存、无通用矩阵依赖。正式入口为`Odometry_Update_Position_ESKF()`，轮位置增量负责SE(2)平移。完整参数与来源见[算法说明](../project/Core/Algorithm/Chassis/README.md)。

本轮1852个RUN遥测帧中，ESKF−AHRS YAW的RMS为0.02818°，最大绝对差0.13237°。这是跟随差异，不是对真实方向的误差。AHRS YAW与gyro同源，相关性不能忽略；增加该ESKF不会凭空获得绝对航向，也不消除共同尺度误差。

停车后读出的偏置估计0.0003863rad/s；最后一拍YAW增益0.10845、轮偏置增益0.00004004。两者作用于不同观测，不能直接解释为融合百分比。1MHz TIM2测得真实里程计入口最后一拍38µs，启动至本轮结束最大观测42µs，约为10ms控制周期的0.42%；包含可能的抢占，不是WCET证明。计时和调试变量只在测试固件编入。

最长主机选中遥测间隔120ms，RUN内IMU最大年龄9ms、里程计最大年龄1.968ms；电机MOS温度最高39℃。未出现DAP超时或保护停车。

## 现场少转约30°后的检查

用户说“平顺，相差可能为30度，少转”。此为目测估计，没有尺量/外部角度真值。若仅作量级换算，30°占30圈约0.28%，**没有用这个估计写入gyro比例修正或强制补角**。

随后只读USART6观察静止数据。打开串口残留的2个旧帧与新数据相隔109.4s，分析明确剔除；未把开头到末尾的129.4s误当本次20s静止实验。有效连续500帧、19.96s、每帧40ms：YAW变化+0.2404°，gyro积分+0.2343°，轮角变化+0.0096°，ESKF变化+0.2354°，估计平移变化0.0089mm。25Hz输出的瞬时gyro均值受采样混叠影响，不用于替代控制周期内积分或写入零偏。

这段静止漂移不足以单独解释目测30°，但也不能排除运动前后零偏变化。动态ESKF跟随差小于0.14°，没有证据把少转归因于ESKF滞后。原代码BMI088 ±2000°/s灵敏度与Bosch的16.384LSB/(°/s)一致；[官方数据手册Rev1.9第10页](https://www.bosch-sensortec.com/media/boschsensortec/downloads/datasheets/bst-bmi088-ds001.pdf)给出该量程25℃灵敏度容差±1%。尺度误差是待排查的可能性，不是已确认原因。后续应以独立视觉/角度标记验证正反向多圈角度，再分别标定gyro尺度和轮几何。

## 通信尝试与失败保留

最初bulk后端在约2.35轮计圈处心跳写超时，STOP确认失能。下一次尝试因串口返回上一请求的DONE而被主机误认为新任务完成；已经增加“观察到新RUN零基线后才允许完成”的回归。再一次bulk到约12.48轮计圈时超时并确认STOP。移到本地临时目录写日志、提高主机优先级、移除运动中SWD诊断读取均未完全解决bulk长尾。

同一探针改为HID后端后，旧30轮计圈及新30YAW计圈均完整运行。重现入口`project/openocd-daplink-hid.cfg`，使用OpenOCD0.12支持的`cmsis_dap_backend hid`；见[官方适配器文档](https://openocd.org/doc-release/html/Debug-Adapter-Configuration.html)。没有放宽心跳或停止期限。新的实验启动器曾在Windows进程优先级设置处失败，当时尚未连接板端或启动运动；修正64位HANDLE声明后运行成功。该启动器为本地一次性产物，不纳入固件。
