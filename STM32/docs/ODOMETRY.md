## 坐标、采样与有效性

车体 `vx` 向前、`vy` 向左，单位m/s；轮角位置单位rad、轮角速度单位rad/s；航向俯视逆时针为正。位置与速度都先按电机方向和齿比换算，位置增量用于平移积分，轮速正解继续输出为诊断速度。轮半径仍为35mm，中心到轮接地点仍为108mm。位移在INS零航向所定义的固定平面坐标系中累计，不能直接当作相机坐标或场地图坐标。

按用户确认的轮位和现有 120°布局，令 `L=0.108 m`、`r=0.035 m`：

| CAN ID | 轮位 | 接地点 (x,y) | 几何轮速正切向 |
| --- | --- | --- | --- |
| 1 | 后轮 | (−L,0) | (0,−1) |
| 2 | 右前轮 | (L/2,−√3L/2) | (√3/2,1/2) |
| 3 | 左前轮 | (L/2,√3L/2) | (−√3/2,1/2) |

每轮将接地点速度 `(vx−wz*y, vy+wz*x)` 投影到自己的正切向，再除以半径。几何轮速为 `q1=(−vy+L*wz)/r`、`q2=(√3*vx/2+vy/2+L*wz)/r`、`q3=(−√3*vx/2+vy/2+L*wz)/r`；电机安装方向均为 −1，因此 MIT 目标为 `−q1/−q2/−q3`。反解为 `vx=r*(q2−q3)/√3`、`vy=r*(−2*q1+q2+q3)/3`、`wz=r*(q1+q2+q3)/(3L)`。

原代码只校正过纵向，横向仍与此布局相反，正逆解互算可以自洽而不能证明物理方向正确。本次同时修正横向逆解、反馈正解和力矩前馈，保留已实测的前进与转向符号：前进的 MIT 符号为 `[0,−,+]`，左移为 `[+,−,−]`，逆时针为 `[−,−,−]`。旧横移及带旋转轨迹的估计结果不能作为修正后模型的标定证据。

底盘任务在短临界区内一次复制三轮的位置、速度、ID、状态、接收时间和序号。只有三轮各自的序号都相对上次接受组更新，才有新的积分组；一轮高频重复上报不能代替另外两轮的新证据。三轮仍非硬件同步采样，临界区只保证读取过程不被CAN接收更新打断。

三轮位置按各自的 CAN 接收时刻分段线性插值。首组以最晚轮反馈时刻建原点，后续每组积分到三轮均已覆盖的最新时刻。每轮保留 64 个毫秒槽，快轮在慢轮追上前发生换向时，过去各段仍按各自的角位移结算。静止编码器配非零速度反馈时，平移保持为零。

发布的航向对应控制拍。新的可信 INS 航向按陀螺与帧龄推到控制拍，平移积分使用轮区间起止时刻的航向。`sample_time_us` 记录接受反馈组的控制拍，运动中的 x/y 会滞后相应的轮反馈年龄。CAN 和 INS 的年龄都在 RTOS 毫秒时钟内计算，控制拍间隔使用 TIM2 微秒时钟。

| 条件 | 处理 |
| --- | --- |
| 三轮反馈 | ID、状态和数值须有效，均未超过 30 ms |
| IMU | 采用同一次 INS 解算快照，样本未超过 20 ms |
| 积分时间 | 使用实际采样间隔，单步最长 50 ms；过长的未知路段不截短后冒充有效积分 |
| 尚未形成完整新组 | 不把重复反馈当成新的位移样本 |
| 反馈/姿态失效或时间断档 | 标记里程计无效，丢失期间不补积分 |
| 恢复首个有效组 | 仅建立新的速度、航向与时间基线，后续有效组再累计位移 |

恢复后不能还原断流期间已经发生的真实位移。`valid` 表示当前估计可用于控制，不保证整段历史轨迹没有缺失。定距运行期间失效会进入故障停车，恢复数据不会自动续跑原动作。

## 2026-11-18 地面原地旋转 35 圈

本轮在地面逆时针连续旋转，以展开的板载 AHRS 航向计圈。五档各 7 圈，沿用 1.6 rad/s² 斜坡、300 ms 心跳、120 s 时限和 0.35 m 估计位移围栏。每段取换档 1.6 s 后的稳定区间，最后一段剔除减速区间。实测均速由区间航向增量除以板端经过时间得到。

| 累计圈数区间 | 请求角速度（rad/s） | 实测稳态均速（rad/s） |
| --- | ---: | ---: |
| 0–7 | 2 | 1.9834 |
| 7–14 | 3 | 2.9799 |
| 14–21 | 4 | 3.9802 |
| 21–28 | 3 | 2.9821 |
| 28–35 | 2 | 1.9821 |

板端动作耗时 86.30 s。AHRS 累计 35.00325 圈，陀螺积分 35.00364 圈，轮编码器 35.04873 圈。编码器比 AHRS 多计 16.37°。末端里程计相对起点为 (−1.27, −11.27) mm，离起点 11.34 mm，过程最大 12.18 mm。地面真实角度和位移缺少外部测量。三台电机 MOS 最高 39 °C，运行帧无故障或无效里程计。停车后收到命令回执及三轮失能反馈。

## 读取与重置接口

接口和 `Chassis_Loop()` 均由同一底盘控制任务调用；本轮没有增加供其他任务并发写入的入口。

- `Chassis_Get_Odometry(out)`：复制最近位姿和有效状态。估计无效时仍返回最后位姿并将 `valid` 置 0，函数返回 0；空指针也返回 0。调用方必须检查有效性，不能把保留的历史坐标当成本帧位置。
- `Chassis_Reset_Odometry(void)`：返回 `uint8_t`，清零平移位置和历史基线。只有底盘失能或三轮已经确认停车时允许重置，运动中拒绝。重置后的首个有效 IMU 航向保留 INS 原有零参考，不把当时车头方向重新定义为零；平移原点可以重置，坐标轴仍按 INS 零向。
- `Chassis_Distance_Start(direction, distance_m, speed_limit_mps)`：保留原调用形式，起步还要求有效里程计。其余待命、使能、姿态和转向尾段衔接条件以 [chassis.h](../project/Core/Control/Chassis/chassis.h) 为准。

位姿当前由 STM32 本地接口读取，未增加 USB 位姿帧或 ROS `odom` 发布。Jetson 继续使用现有动作与到达握手。

## 单段定距闭环

接受动作时保存起始位姿和本段目标方向。进度是估计位移沿固定目标方向的有符号投影，不是累计路径长度；横向漂移或原地转向不能被当作沿目标轴前进。转向剩余不超过 5° 时接定距，仍保留原转向终点航向并由现有航向 PID 修偏。

| 参数 | 当前值与含义 |
| --- | --- |
| 最短请求距离 | 0.010 m，小于该值拒绝 |
| 位置到位容差 | 0.003 m，软件估计位置的判据 |
| 发零速的内层门槛 | 剩余位移不大于 0.0015 m，给停车小幅回退和量化留余量 |
| 位置比例增益 | 2.0 s⁻¹，根据剩余位移生成速度约束 |
| 末段接近速度 | 最低候选值 0.010 m/s，仍受本段请求限速、制动速度与原加速度斜坡约束 |
| 合速度上限 | 沿用本段请求限速，最高 0.50 m/s |
| 加减速度上限 | 沿用 0.75 m/s² |
| 制动速度约束 | 根据实测剩余距离限制为 `sqrt(2*a*remaining)` |
| 无进展期限 | 连续 1500 ms 无有效进展进入故障制动 |
| 总时限 | 原理想限速轨迹时间的 3 倍加 2000 ms |
| 到位交接 | 自动流程在零目标提交、终点有效后转段。专用静态验收仍要求三组停车反馈 |

进入内层门槛后发零速，在交接前按 3 mm 容差核对终点。自动流程可在车轮减速期间接续下一段。调参工具仍可通过 `Chassis_Is_Stopped()` 等待三组静止反馈。终点在验收前重新越界、反馈失效、无进展或总时限到期，均触发故障停车。

这是沿指定方向的单段定距控制。3 mm 是估计值的到位门槛，不代表轮胎与地面之间已有 3 mm 定位精度；横向误差、打滑、轮径与齿比误差、六轴航向漂移仍须实测。不能仅凭里程计数值判断越障或搬运真实位置正确。

## 实车复核

1. 保持自动关闭，先架空验证轮序、方向和单位：前后与左右平移的估计方向应一致，纯旋转不应产生明显平移。确认断反馈、异常状态和 IMU 失效会使里程计无效，并按现有控制逻辑停车。
2. 在已确认停车后重置平移原点，保持车辆静止读取位姿，核对静态漂移及 IMU 航向。再在平整场地低速、空载执行已量好的直线距离，分别记录估计位移、尺量位移和停车余量。
3. 分别重复前后、左右、四个斜向和转向尾段接定距。复核位置到位后到三轮实际停转之间的位移，确认原地旋转、横向漂移和反馈重复不能误报距离完成。
4. 加入实际地面、负载和减速带条件，复测轮滑、姿态漂移、制动与无进展处理。确认控制精度和停车效果后，再填写三段自动距离并按 [板间联调流程](JETSON_USB_TEST.md)验收完整搬运。

历史记录中的指令积分、旧停车距离和用时只属于当时版本；本轮新增反馈闭环须重新进行以上板端复核。

## 2026-11-17 DAP-Link / USART6 短距离实测

车辆放在地面空旷区域，使用 Horco CMSIS-DAP v2（SWD 480 kHz）控制，USART6（115200、8N1，电脑 COM7）记录 56 通道 JustFloat。原板内 1 MB Flash 已备份；测试固件采用六轴、自动关闭、显式命令启动。三台电机读回位置量程均 12.5 rad、速度量程均 40 rad/s、力矩量程依次 1/1/2 N·m，与工程配置一致。

| 板端项目 | 结果 |
| --- | --- |
| 静态使能保持 1 秒，两次 | 估计位移模长约 0.130 / 0.061 mm；有效里程计，停稳后确认三台失能 |
| 首次前进 50 mm、限速 0.05 m/s | 末段触发零速后积分位置小幅回退，最终保存进度 46.936 mm；超出 3 mm 容差，保护停车失能，明确判失败；不是独立地面回退测量 |
| 修正后前进 50 mm | 沿锁定方向估计 48.511 mm，误差 −1.489 mm，2.240 秒；有效终点、停稳和三台失能均确认 |
| 修正后后退 50 mm | 沿后退方向估计 48.611 mm，误差 −1.389 mm，2.140 秒；有效终点、停稳和三台失能均确认 |
| USART6 与 SWD 核对 | 静态及首次运动中共同时间戳的 56 通道数值一致，运行帧里程计有效 |

首次运动暴露了外层到位边界停车后积分位置变化的问题，低速反馈也显示末段接近较慢。本次将停车触发收至 1.5 mm 内层，并加入受请求限速/制动速度/加速度约束的 0.010 m/s 末段候选速度；最终 3 mm 验收及越界保护不变。主机新增 0.005 m/s 死区和 0.12 mm 停车回退模型，前后通过；低于候选速度的请求仍不超限。该模型不是对实车机械回退或摩擦原因的证明。

首轮静态结束后主机日志曾因重复 `command` 字段异常，但板端完成及最终 STOP 均已确认；已修复并通过真实结果字段回归，后续静态和运动会话正常结束。更新后的 27 套主机回归、9 种控制模式预处理、25 项主机脚本测试及五种 ARM 构建（专用测试、六轴 Debug 手动、九轴 Release 手动、自动、底盘测试）通过。
